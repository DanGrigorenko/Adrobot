# Keitaro Wrapper

Интерфейс создания кампаний Keitaro и управления офферами в их потоках.

## Язык

### Кампания

Настройка в Keitaro, объединяющая потоки для маршрутизации входящего трафика.

### Поток

Часть кампании Keitaro с условиями отбора трафика и действием для подходящего посетителя.

### GEO

Одна или несколько выбранных стран. В Campaign Creator страна посетителя определяет, попадёт ли он в поток на Google.

### Поток по умолчанию

Поток Keitaro для трафика, которому не подошли предыдущие потоки кампании. В Campaign Creator он ведёт на выбранный оффер.

### Оффер

Запись каталога Keitaro, которую оператор выбирает в качестве назначения для трафика потока.

### Привязка оффера

Связь конкретного оффера с конкретным потоком. У неё есть собственные доля трафика и состояние.

**Доля трафика**:
Часть трафика потока, назначенная привязке оффера, в целых процентах; не относительный вес.

**Закрепление (Pin)**:
Свойство привязки в конкретном потоке, сохраняющее её долю при автоматическом перераспределении в Editor. Снятие закрепления (Unpin) возвращает привязку в автоматическое распределение.

**Активная привязка**:
Существующая в потоке неотключённая привязка, участвующая в распределении трафика. Доля 0% не делает привязку отключённой или удалённой.

**Черновик потока**:
Предлагаемое состояние привязок одного потока, ещё не опубликованное в Keitaro.

**База черновика**:
Исходное состояние привязок потока в Keitaro, относительно которого подготовлены изменения черновика.

**Публикация потока**:
Применение подготовленного состояния привязок одного потока в Keitaro.

**Удалённая привязка (Removed)**:
Привязка, удалённая через Editor и доступная для возврата. Удаление привязки не удаляет сам оффер из каталога Keitaro.

**Отключённая привязка**:
Существующая в потоке привязка со статусом `disabled`; в отличие от удалённой, она остаётся частью конфигурации потока.

### Префикс кампании

Начало имени кампании, по которому на тестовом стенде распознаются кампании, созданные конкретным исполнителем.
